# Eurobot 2027 - Software de visión

Ejecutar comandos en eurobot_ws, dos carpetas anteriores. Necesario hacer los pasos de [eurobot_software](https://github.com/star-uma/eurobot_software.git).

## Lanzamiento nodo de visión

Nodo para simulación que despliega una ventana para la visuañización de la cámara.
```bash
ros2 run eurobot_software_vision vision_node 
```
